# 首轮本地模型凭据主密钥

- 编号：DEC-20260927-003
- 日期：2026-09-27
- 状态：已确认，仅适用于本地单人合成资料验证
- 决策人：项目发起人
- 依据：[MPX-003 原始回复](../questions/2026-09-27-003-model-credential-key.md)、[模型接入决定](../questions/2026-09-27-001-model-access.md)

## 结论

本地主密钥保存在仓库与 PostgreSQL 之外的 WSL 用户专用位置，只向模型代理只读注入。首轮接受该密钥丢失后重新录入供应商凭据；原密文不可恢复。主密钥不得复用数据库密码，应用启动不得自动生成新密钥覆盖旧密文。

## 后果与复查

数据库备份本身不足以恢复模型凭据。模型代理须在密钥缺失、格式错误或解密认证失败时拒绝使用连接，并仅返回脱敏错误。生产、多用户、跨机器恢复与密钥轮换需另行设计；本决定不承诺这些能力。
