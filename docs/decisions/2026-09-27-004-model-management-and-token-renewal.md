## 结论

1. 管理写入使用仓库外随机本地管理员密钥完成一次认证；API 建立短时、HttpOnly、SameSite 会话，并对写入请求检查 Host、Origin 和 CSRF 令牌。回环地址本身不构成管理员授权。
2. 控制 API 可在内存中短暂接触供应商凭据并通过鉴权内部通道交给模型代理加密；API 不持解密主密钥，不持久化、记录或回显明文。
3. 运行中令牌由控制域轮换：先保存新摘要，再原子更新任务专用文件，短暂交叠后撤销旧摘要；文件更新失败时撤销新摘要。停止、删除或更换连接时撤销所有旧授权并取消活动流。

## 后果与实施边界

首个实现可独立交付令牌摘要存储、连接绑定、有限到期、轮换交叠与撤销原语，但不把它宣称为任务生命周期集成。管理会话、服务间鉴权、正式只读挂载、调度与活动流取消需按后续任务分别验证。令牌有效期、续期触发点和交叠窗口尚未确定；存储原语接受显式到期时间，产品调度器在集成前须确定并验证具体上限。生产、多用户及远程访问另行评估。
