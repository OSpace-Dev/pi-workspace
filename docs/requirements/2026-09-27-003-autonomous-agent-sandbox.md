# 自主配置的独立 Agent 沙箱

- 日期：2026-09-27；状态：本地增量已实现并通过合成验收；[SBX-005](../questions/2026-09-27-005-autonomous-sandbox-egress.md) 已确认
- 决策人：项目发起人；执行人：Codex
- 依据：2026-09-27 用户对控制平面、Pi Web、探针和资源占用的直接反馈；[历史沙箱需求](2026-09-27-002-pi-web-sandbox.md)

## 目标与范围

控制平面让管理员快速创建、启动、停止、恢复和删除独立 Agent 沙箱，并提供进入该沙箱专属 Pi Web 的入口。模型、提供商凭据及其他 Pi 能力由该沙箱内的用户独立配置与持久化；创建沙箱不要求先建立控制平面模型连接，控制平面不代为选择模型、不发放模型代理令牌。每个沙箱的配置、会话和工作文件互不共享。

控制平面展示每个 Agent 的运行状态。首轮探针可只显示容器运行、Pi Web 就绪和最近活动的可观察摘要；更细粒度的工作事件留待后续。停止释放运行资源，恢复保留沙箱配置、会话与工作目录；删除仍由管理页面显式执行。

## 边界与验收

1. 在 `/sandboxes` 只输入名称即可创建并打开自己的 Pi Web；没有控制平面模型连接时也能创建。Pi Web 内可按 Pi 自身机制配置提供商，配置不会写入控制平面模型连接表或其他沙箱。
2. 两个沙箱具有不同容器、Pi 配置目录、工作目录、访问密码及 Web 入口；各自配置和会话在停止、恢复后仍在。删除其中一个不影响另一个。
3. 管理页能区分启动中、运行、已停止和故障，并显示探针实际采集的状态及采集时间；未知状态不得伪装成空闲。控制平面不读取、显示或记录提供商密钥。
4. 管理 API、数据库和代理服务不在新沙箱模型请求路径。出站能力与信任范围由 [SBX-005](../questions/2026-09-27-005-autonomous-sandbox-egress.md) 决定；容器仍无 Docker socket、非 root、受资源限制，Web 入口仅绑定本机回环并要求独立密码。
5. 验收在独立 WSL Docker 项目完成创建、双实例配置隔离、真实 Pi Web 配置入口、停止恢复、删除及资源清理；结束后不得留下合成验收容器运行。

## 已知限制

沙箱内配置的凭据可被该沙箱内 Pi 进程及其工具读取；沙箱进程也有外发能力。[SBX-005](../questions/2026-09-27-005-autonomous-sandbox-egress.md) 已确认首版仅用于本地可信内部使用，不能据 Docker 隔离承诺承载不可信代码或公开多租户。远程入口、多人权限和配额另行决策。既有资料问答和控制域模型代理保留为历史实现，不作为本需求的默认工作流。
