# 模型连接管理工作台设计

- 编号：HLD-20260927-003
- 日期：2026-09-27
- 状态：本地隔离增量设计
- 依据：[管理与令牌边界](2026-09-27-005-model-management-and-task-tokens.md)、[本地主密钥](../decisions/2026-09-27-003-model-credential-key.md)、[页面规格](../ui/2026-09-27-001-model-management.md)

独立 Compose 项目由回环暴露的控制 API、仅 Docker 网络可达的模型管理服务及独立 PostgreSQL 卷组成。API 持仓库外管理员密钥与服务凭据，不持主密钥或数据库连接；模型管理服务持仓库外 32 字节主密钥、服务凭据及数据库连接。密钥由显式启动脚本在 WSL 用户私有目录初始化，服务启动不得生成或替换。现有 Compose 项目和数据库不迁移。

当前 WSL 自动配置的 DNS 在隔离验收时超时，因此仅预览模型管理容器使用 `8.8.8.8` 作为可回退的开发环境 DNS 假设。目标仍逐次通过公网地址策略校验；此配置不改变现有容器或主机 DNS，生产部署时须按部署环境重新评估。

API 以恒定时间比较管理员密钥，颁发内存中的短时不透明会话 cookie；写入要求精确 Host、Origin 和 CSRF。服务间请求仅接受独立随机凭据，不暴露宿主端口。双方禁用请求正文日志，并给 JSON 体设上限。模型管理服务使用既有 origin 策略、DNS 公网检查与 AES-GCM 存储。连接创建在事务内重新核对 origin 批准状态；停用和凭据更换使用 `updated_at` 乐观并发条件。列表只返回元数据与凭据已配置布尔值。

管理面无需任务状态，因此停用连接会使未来授权查询拒绝，但活动流取消留到任务代理集成。真实模型调用及供应商兼容性未在本增量验收。
