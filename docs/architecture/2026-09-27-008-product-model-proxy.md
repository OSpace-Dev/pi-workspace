## 本轮边界

模型代理增加仅内部网络可达的 Pi `POST /v1/chat/completions`。控制域通过已有服务凭据创建和停止代理任务；任务记录表示模型调用授权状态，不表示 Pi 容器已经运行。正式运行代理、只读令牌文件、自动轮换、恢复/删除/换连接和文档问答页面另行交付，不能把本轮任务状态误作完整容器生命周期。

`model_proxy_tasks` 保存任务 ID、固定连接 ID、`active/stopped` 状态和时间。创建时在一个数据库事务中锁定连接、插入任务并签发首个令牌摘要；原值仅在创建响应中返回。停止时在同一任务锁和事务下先改状态再撤销授权；提交后取消本进程登记的活动流。代理每次调用核对令牌摘要、时间窗口、任务状态、绑定连接及连接启用。授权后先登记 `AbortController`，再复查状态；因此停止与鉴权交错时，流要么无法开始，要么在停止返回前被取消。此保证仅覆盖当前单实例代理；多实例部署需共享取消信号。

## 模块与请求路径

管理入口保留连接管理路由；任务控制、Pi 请求校验、代理流服务及活动流登记各自承担单一职责。控制 API 和页面当前不暴露任务令牌。管理页面按会话、API 客户端、连接和 origin 视图拆为原生 ES modules，以真实 URL 路径区分现有两页；不引入未选定的框架或空页面。

Pi 请求仅接受实测字段 `model`、`messages`、`stream`、`stream_options.include_usage`、`max_completion_tokens`。纯文本消息、模型 ID、请求字节数和完成 token 上限在进入上游前校验；不接受目标、头部、工具或其它字段。代理从数据库读取当前批准 origin 与加密连接，逐次重新解析 DNS 并取得策略 IP，解密凭据后交给固定 IP HTTPS 传输。传输保持原域名 Host、SNI、证书校验；3xx 直接拒绝。真实凭据和任务令牌不进入日志或返回体。

首响应限定 15 秒，流空闲限定 30 秒；请求体上限 1 MiB，最多 64 条消息，`max_completion_tokens` 限定 1～4096，省略时补 4096。单任务最多一条活动流，单进程最多八条，流总字节上限 4 MiB。这些是首轮可回退的技术保护限额，不代表多人容量承诺。上游首响应失败返回稳定的无敏感内容错误；流开始后中断或缺少 `[DONE]` 直接关闭下游，不补成功标记，不重试。下游断连也取消上游。逐字节流转发保留 Node 管道背压；本轮只检查 OpenAI 正常结束标记，不转换供应商 SSE 数据，Pi 对上游方言的兼容性仍需逐连接验证。受控 Pi 配置关闭 `retry.enabled` 并设置 `retry.provider.maxRetries: 0`；产品代理无法阻止不受控客户端自己重复提交。

控制 API 按启动、应用装配、管理员会话、管理转送和页面路由拆分。会话 cookie 名称按本地公开 origin 区分，避免两个隔离预览端口互相覆盖；现有预览实例不重启。新增预览使用独立 Compose 项目和数据库卷，API/代理用 WSL 用户 UID/GID 读取仓库外只读密钥，保留 `cap_drop: ALL`。管理连接操作保持既有契约。

## 验证与后续

使用隔离 PostgreSQL、合成任务令牌与合成 TLS/SSE 上游验证请求约束、状态与撤销竞态、活动流取消、认证头、IP 固定和错误脱敏。策略与真实传输的独立测试继续运行；合成端到端测试通过注入策略结果接到本机 TLS 夹具，不给产品策略增加私网例外。不得迁移现有管理预览或开发数据库。正式 Pi 容器接入时再验证只读文件挂载、轮换对账和跨容器停止。
