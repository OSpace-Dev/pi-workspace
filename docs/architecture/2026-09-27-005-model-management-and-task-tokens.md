## 现状与设计范围

`codes/` 已有健康检查 API、内部连接存储、目标策略、固定 IP HTTPS 传输、任务令牌表及[本地模型管理工作台](../planning/2026-09-27-010-model-management-console.md)；尚无正式任务表、产品模型调用入口或运行代理。已确认：管理员批准 HTTPS origin；任务专属不透明令牌只存摘要，绑定任务与连接，停止、删除、切换时撤销，恢复签发新令牌，运行中续期；模型代理独占凭据解密主密钥。首轮仅本机回环单人验证，不代表生产或多人授权。

本设计覆盖连接管理入口、明文凭据流经边界、内部写入鉴权与任务令牌状态。网页表单及独立管理容器已由本地工作台任务交付；完整产品代理和任务容器编排仍是后续任务。任何连接管理写入都不能借无鉴权健康接口发布。

## 建议的数据流与信任边界

1. 浏览器只访问回环暴露的控制 API。管理写入使用仓库外本地管理员密钥认证后的短时 HttpOnly、SameSite 会话，并检查 Host、Origin 和 CSRF；还需请求体上限与敏感字段日志屏蔽。`/health` 和 `/ready` 不执行管理操作。
2. 新建或更换连接凭据时，浏览器经 API 将明文送到不暴露宿主端口的模型代理管理入口。API 仅瞬时转送、从不存储或记录明文；模型代理规范化并检查已批准 origin、封装凭据写入数据库。API 与代理间必须有独立服务鉴权，不能把 Docker 网络可达性当成授权；凭据不得经过运行代理。
3. 模型代理持有数据库访问权和外部主密钥，只在已授权的模型调用中解密。API 的连接列表只返回元数据和 `credentialConfigured`，不能返回密文、标签、明文或可用于请求上游的令牌。代理到上游每次重跑目标策略并使用策略 IP、原域名 TLS 校验和无重定向传输。
4. 管理操作的审计仅记录操作类别、主体、连接 ID、成功/失败类别和时间；不得记录认证 cookie、代理令牌、凭据、请求正文或完整上游 URL。数据库连接权限与迁移职责需在实施任务中明确，不能把目前测试数据库凭据作为最终权限设计。

控制 API 与模型代理的内部管理通道建议使用独立随机服务凭据、仅内部网络可达和双方请求超时；服务凭据从仓库外注入，不复用模型主密钥、数据库口令或任务令牌。服务间 TLS 在本地 Docker 网络中的具体实现及远程部署边界后续复核；这里不将网络隔离等同于加密。

## 连接变更与一致性

- 批准 origin 只影响以后可保存的连接，运行前仍以当前批准清单重新验证。撤销 origin 时必须阻止对应连接的新请求，并明确现有任务处理策略；建议拒绝仍有关联连接的删除并要求先停用/迁移，以免静默改变运行任务。
- 连接创建在单次数据库事务中确认 origin 仍获准并写入密文；DNS 校验可在事务前进行，提交前再次核对批准状态。当前存储函数的先读清单、再独立写入有并发窗口，产品写入任务需收紧。
- 连接停用或目标/模型/凭据变更须界定已有任务。建议首轮不原地修改连接目标或模型：建立新连接，显式切换任务并撤销旧授权。凭据更换时建议先阻止新调用、写入新密文、再恢复；进行中的流如何取消须与任务协调。
- 连接删除、origin 撤销和凭据轮换的精确管理语义在契约确认时固定。未确认前只可实现与这些行为无关的内部技术验证。

## 任务令牌建议状态机

目标任务记录与授权记录位于同一数据库，任务主表尚未实现。已验收的授权表保存随机令牌的 SHA-256 摘要、任务 ID、连接 ID、签发/到期/撤销时间，以及前任授权和轮换完成时间；原值只在签发或轮换时返回控制域。令牌具有 256 位随机熵，不能从数据库重新取回明文。产品代理仍须核对任务状态及连接绑定。

| 事件 | 数据库与容器动作 | 调用边界 |
| --- | --- | --- |
| 首次启动 | 持久化任务和连接绑定，签发令牌后写入该任务专用配置，再启动 Pi | 仅已启动且授权未过期的任务可发起新调用 |
| 正常运行/空闲 | 控制域在到期前续期；候选为先持久化新授权、再原子更新任务专用文件、最后废止旧授权 | 文件更新失败时撤销新授权；旧授权到期后拒绝新请求，并向任务显示故障 |
| 停止/删除 | 先在数据库事务中撤销所有授权并阻止新调用，再取消活动流、停止/删除容器；失败记录可重试状态 | 旧令牌不能再发起请求；已有流不能继续计费 |
| 更换模型连接 | 先撤销旧连接授权；新连接就绪后签发绑定新连接的令牌并更新任务配置 | 不允许旧令牌访问新连接 |
| 恢复 | 核对保留容器与会话，签发全新令牌并更新任务配置，然后恢复 Pi | 停止前令牌永不恢复有效 |

数据库事务无法与 Docker 文件写入/启动形成原子提交；需要可恢复的中间状态、幂等操作及重启对账。轮换交叠时新旧授权只能绑定同一任务与连接。[MPX-007](../decisions/2026-09-27-005-task-token-window.md) 已确认 1 小时有效期、到期前 10 分钟轮换和最多 5 分钟交叠；[内部存储增量](../planning/2026-09-27-009-task-token-window.md)已强制有效期与交叠上限，但尚无调度器。代理在每次新请求时检查摘要、任务状态、连接绑定、有效期和撤销时间。停止时还需取消正在进行的上游流，不能仅凭新请求鉴权。错误和日志不回显令牌。

Pi 0.87.1 的 [`models.json` 文档](../../refer/pi-main-0.87.1/packages/coding-agent/docs/models.md)和 [`resolve-config-value.ts`](../../refer/pi-main-0.87.1/packages/coding-agent/src/core/resolve-config-value.ts)显示，以 `!` 开头的 `apiKey` 在请求时由 shell 命令读取且该解析路径不缓存。隔离探针已实测同一 Pi 进程两轮请求分别使用旧、新合成令牌。候选配置是由控制域固定的只读 `models.json` 命令读取任务专用令牌文件；控制域在轮换时原子替换文件，Pi 只读，其他任务不能挂载该目录。正式运行仍须验证只读挂载和优先级更高的运行参数或 `auth.json` 不会覆盖此配置。不得把可编辑命令或真实供应商密钥交给任务。
