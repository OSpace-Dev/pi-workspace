一个连续周期交付管理入口、新建两个独立沙箱、各自可登录 Pi Web、模型代理授权、停止恢复删除。范围覆盖迁移、runtime/gateway、安全配置、服务契约、页面和真实 WSL Docker 端到端；不做 PDF/IM/生产部署/多租户。现有文档问答保留且回归。动态端口、沙箱默认工具能力属于本地独立新类型的明确范围；其权限受容器约束，不放宽原 QA 类型。

验收按需求 1～5；执行类型/数据库/真实容器/浏览器和归属检查。使用全新 Compose 项目及端口，不重建用户现有容器。完成需复审与测试记录；真实供应商兼容单独记录限制。

## 结果

- 管理端 `/sandboxes` 可创建、查看、停止、恢复、删除独立 Pi Web 沙箱；每个 Web 有独立随机密码、动态回环端口、工作目录、Pi 会话和模型任务授权。`/tasks` 继续只接收资料问答类型。
- 模型代理对沙箱接受受限函数工具请求，QA 原有无工具契约不变。合成上游验证了 `write` 工具调用在沙箱目录落文件、流式回答与会话刷新/停止恢复。
- [只读复核](../reviews/2026-09-27-013-pi-web-sandbox.md)未发现阻断项；验收覆盖双实例隔离、登录、模型与工具会话、生命周期和桌面/手机页面。真实供应商语义、生产入口、多租户与强隔离仍未覆盖。
