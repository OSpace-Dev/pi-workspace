# 可操作的本地模型连接工作台

- 编号：TASK-20260927-009
- 日期：2026-09-27
- 状态：已完成；本地管理增量通过隔离验收
- 执行负责人：Codex；产品决策人：项目发起人
- 依据：[Backlog 2B](2026-09-26-001-initial-backlog.md)、[管理设计](../architecture/2026-09-27-007-model-management-console.md)、[页面规格](../ui/2026-09-27-001-model-management.md)

目标是在独立 WSL Docker 项目中交付浏览器可操作的模型连接管理页面。范围含本地管理员登录、origin 批准与列表、连接创建与列表、停用、凭据更换、服务间鉴权、隔离 PostgreSQL 及可重复验证。非目标为任务代理、实际供应商调用、多人授权和现有数据迁移。

完成定义：浏览器能完成上述管理流程；无授权、CSRF/Host/Origin 错误和无效目标被拒；API 不持主密钥，浏览器响应不含凭据；类型与集成检查通过；现有容器和卷不变；记录评审、验收与剩余风险。容量假设为一个跨 API、代理、页面与容器配置的连续增量。

2026-09-27：工作台已在独立 `piws-admin-preview` 项目运行。见[评审](../reviews/2026-09-27-009-model-management-console.md)和验收。下一步为产品模型代理与任务生命周期的设计、实施和 Pi 流式验收。
