## 目标与边界

在隔离 PostgreSQL 中提供内部任务代理令牌授权原语：随机不透明令牌只在签发或轮换时返回，数据库仅存摘要；授权绑定任务 ID、模型连接 ID 和有限到期时间；可验证、完成轮换、失败回滚新令牌及撤销全部授权。

- 包含：版本化迁移，事务串行化的首次签发与单次轮换交叠，过期/撤销/禁用连接拒绝，合成数据集成测试。
- 不包含：任务主表及状态机、Pi 容器文件写入、续期调度、活动流取消、管理 HTTP API、现有 Compose 数据库迁移或真实供应商凭据。
- 依赖：已验收的连接存储与独立 WSL Docker 测试环境。
- 可回退技术假设：存储原语由可信控制域调用并接收显式到期时间；具体有效期和交叠窗口由后续运行集成任务设定。任务 ID 暂以 UUID 关联，不能据此推断任务主表结构。

## 完成定义与验证

1. 256 位随机原值不在数据库列、元数据、错误或日志中；相同任务的授权不能绑定其他连接，未完成轮换不得再签发第三个有效令牌。
2. 新旧令牌在轮换交叠期均可验证；完成轮换后仅新令牌有效；写文件失败时可单独撤销新令牌并保留旧令牌；全量撤销及到期后均拒绝。
3. 对禁用或不存在的连接拒绝签发和验证，跨任务/跨连接使用拒绝；并发调用不得绕开单次轮换约束。
4. 迁移可重跑；TypeScript 检查、聚焦测试和相关存储回归在隔离 WSL Docker 通过；临时数据库/网络清理，现有容器与数据卷保持原状。
5. 只读评审、验收证据和剩余集成风险写回任务与 Backlog。
