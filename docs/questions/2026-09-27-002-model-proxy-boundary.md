# 模型代理的上游与任务令牌边界

- 日期：2026-09-27
- 状态：MPX-001～002 已回复；技术落实见模型代理边界决策
- 决策人：项目发起人
- 关联：[模型代理设计](../architecture/2026-09-27-002-model-proxy.md)、[接口草案](../api/2026-09-27-001-model-proxy.md)、[Backlog 2A](../planning/2026-09-26-001-initial-backlog.md)

现有决定已要求支持可配置的 OpenAI 兼容第三方 API，并由控制域代理持有真实密钥。Pi 的任务容器可能被任务内容影响，因此代理不能把它提供的 URL 或模型 ID 当作可信配置。以下两项只涉及模型代理的安全契约；无凭据的固定测试上游协议验证不依赖这些回答。

## MPX-001：真实上游地址由谁允许？

1. 管理平面维护获准的 HTTPS 域名或 origin 清单，模型连接只能选用清单中的目标（建议）。新增供应商需管理员加入清单；代理禁止重定向，拒绝私网、回环、链路本地和非 HTTPS 目标，并校验 DNS 与最终连接地址。可配置供应商仍然可用，但新增目标需要管理动作。
2. 管理平面接受任意 HTTPS URL，代理仅靠私网地址检查与禁止重定向拦截危险目标。配置更自由，但 DNS 变化、代理链路和新地址类型更难防护，错误配置可能访问内部服务。
3. 其他，请说明允许范围和本地模型服务是否属于首轮。

回答区：1

结论与日期：2026-09-27 选择方案 1。真实上游连接只能使用管理员批准的 HTTPS origin；禁止重定向和非公网连接。具体校验及连接方式见[模型代理边界决策](../decisions/2026-09-27-002-model-proxy-boundary.md)。

影响：模型连接表单、代理出站策略、SSRF 防护、第三方供应商接入流程。

## MPX-002：任务代理令牌何时失效？

1. 控制平面为每个任务生成随机不透明令牌，只存摘要并绑定任务与模型连接；任务停止、删除或模型连接变更立即撤销，恢复时发新令牌（建议）。运行中的令牌设置有效期，并在控制域续期；需要实现续期及恢复配置写入。
2. 令牌在任务从创建到删除期间保持有效，停止时不撤销。恢复较简单，但停止的容器或泄露的旧令牌仍能调用模型并产生费用。
3. 其他，请说明撤销点与恢复方式。

回答区：1

结论与日期：2026-09-27 选择方案 1。每任务令牌绑定任务和模型连接，仅保存摘要；停止、删除或切换连接时撤销，恢复时重新签发。运行中令牌须到期并由控制域续期；具体时长与续期实现将在任务生命周期设计中确定。

影响：任务生命周期、数据库授权记录、恢复流程和费用控制。不要在本文填写真实令牌或供应商密钥。
