# 模型管理授权与任务令牌续期决策

- 日期：2026-09-27
- 状态：MPX-004～007 已回复并归档；本地单人增量适用
- 决策人：项目发起人
- 关联：[管理与令牌设计](../architecture/2026-09-27-005-model-management-and-task-tokens.md)、[管理接口草案](../api/2026-09-27-002-model-management.md)、[Backlog 2B](../planning/2026-09-26-001-initial-backlog.md)

首轮是本机回环、单人、合成资料环境，但管理入口将允许修改外部请求目标并录入可计费的供应商凭据。仅监听 `127.0.0.1` 不能自行证明浏览器请求来自管理员。MPX-002 已确认任务令牌须到期且由控制域续期；MPX-006 进一步确认以轮换方式续期。隔离探针已证明 Pi 同一进程可请求时重读合成令牌，尚未验证正式挂载与事务。以下决定影响管理接口和任务代理的安全契约；内部存储与传输的独立验收不依赖运行窗口数值。

## MPX-004：本地管理写入如何识别管理员？

1. **本地管理员密钥与受保护会话（建议）**：安装时在仓库外生成随机管理员密钥；浏览器由本机管理员完成一次认证，API 颁发短时、HttpOnly、SameSite 会话，并校验 Host/Origin 与写入请求的 CSRF 令牌。增加一次本机认证和密钥保管，但避免任意本机网页直接触发高风险写入。
2. **仅回环地址与同源校验**：无管理员密钥；实现更轻，但同机其他进程可直接写入，错误代理配置、DNS rebinding 或浏览器边界缺陷会扩大风险。
3. **其他**：请写明本地写入授权方式。多人和远程部署另行设计。

回答区：1

结论与日期：2026-09-27，选择方案 1。采用仓库外本地管理员密钥和受保护会话；写入请求校验 Host、Origin 与 CSRF。见[决策记录](../decisions/2026-09-27-004-model-management-and-token-renewal.md)。

影响：批准 origin、录入/更换凭据、停用连接，以及以后任务停止/删除等管理写入。

## MPX-005：录入供应商凭据时，控制 API 可否短暂接触明文？

1. **允许瞬时转送（建议）**：浏览器将凭据送至回环 API；API 做授权与大小校验后经受鉴权的内部通道转给模型代理，由代理加密。API 内存中短暂出现明文，但不持主密钥、不落盘、不写日志、不回显。
2. **明文只进入模型代理**：浏览器针对代理加密后由 API 转送，或另设受保护的直达入口。API 无法看见明文，但需要额外密钥交换、端点暴露或复杂的客户端加密设计。
3. **其他**：请说明可接受的明文接触边界。

回答区：1

结论与日期：2026-09-27，选择方案 1。控制 API 可短暂接触并转送明文，不持主密钥、不落盘、不记录或回显。见[决策记录](../decisions/2026-09-27-004-model-management-and-token-renewal.md)。

影响：管理接口部署拓扑、服务间鉴权、凭据输入与错误处理。

## MPX-006：运行中的任务令牌如何续期？

1. **轮换令牌（建议）**：控制域定期签发新随机令牌，先持久化新摘要，再原子更新该任务专用的只读令牌文件，短暂交叠后废止旧摘要；文件更新失败则撤销新摘要。Pi 0.87.1 每次请求读取文件，合成探针已验证这一点。停止/删除/切换时所有令牌立即撤销并取消活动流。泄露的旧令牌在有限窗口后失效，但正式挂载与故障恢复仍需验证。
2. **延长同一令牌的到期时间**：控制域持续更新数据库有效期，不改 Pi 配置。更易实现，但只要任务持续运行，泄露的同一令牌可持续使用，直到撤销。
3. **其他**：请说明续期与泄露窗口的要求。

回答区：1

结论与日期：2026-09-27，选择方案 1。运行中定期轮换令牌，先保存新摘要，再原子更新任务文件，短暂交叠后撤销旧授权；失败时撤销新授权。见[决策记录](../decisions/2026-09-27-004-model-management-and-token-renewal.md)。

影响：任务授权表、续期调度、Pi 配置挂载、恢复与故障对账。具体有效期和交叠上限在运行集成任务前定稿。

## MPX-007：首轮本地运行令牌的有效期与轮换交叠上限是多少？

内部[令牌存储任务](../planning/2026-09-27-008-task-token-store.md)只接受显式到期时间，不设定调度策略；产品调度器必须决定何时签发新令牌及旧令牌最多共存多久。窗口越长，泄露令牌可继续调用与计费的时间越长；窗口太短则容器文件更新或短暂故障可能中断下一轮请求。停止、删除和切换连接仍立即撤销，不受交叠窗口影响。

1. **15 分钟有效期、到期前 5 分钟轮换、最多 30 秒交叠（建议）**：泄露窗口较短，控制域需能在 30 秒内完成文件更新并确认；失败时须报告任务不可调用。
2. **1 小时有效期、到期前 10 分钟轮换、最多 5 分钟交叠**：对短暂故障更宽容，但泄露令牌可使用更久。
3. **其他**：请写明有效期、轮换触发点和最大交叠时间；不要在本文填写任何令牌。

回答区：2

结论与日期：2026-09-27，选择方案 2。首轮本地运行令牌有效期为 1 小时，到期前 10 分钟轮换，新旧令牌最多交叠 5 分钟。停止、删除、切换连接仍立即撤销。见[决策记录](../decisions/2026-09-27-005-task-token-window.md)。

影响：续期调度、文件更新失败处理、代理鉴权和费用风险。当前先在内部存储强制时间上限；自动调度仍需任务状态与容器更新设计。
