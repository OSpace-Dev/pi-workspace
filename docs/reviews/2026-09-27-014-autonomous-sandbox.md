## 发现

### REV-20260927-014-F001（P2）：旧沙箱升级兼容证据缺失

`codes/src/api/agent-sandbox-service.ts` 在自主沙箱表未命中时分派给历史 TaskService；旧表、旧容器和目录保持原样。但目前只在全新隔离数据库验证了新类型，没有对原 `30207` 的旧沙箱做升级后列表、详情、停止/恢复或删除路径检查。若路由或迁移影响旧数据，当前验收无法发现。补充保留数据的原预览升级检查，不删除旧沙箱。

### REV-20260927-014-F002（P2）：网络隔离检查不完整

`codes/probes/autonomous-sandbox/check.mjs` 检查了各自网络名与文件挂载，但只在第一个沙箱网络中启动合成上游并证明它能访问。未从第二个沙箱尝试访问这个端点；若 Docker 网络配置意外打通，双实例隔离验收仍会通过。增加第二个沙箱的拒绝访问检查。

## 结论

代码路径未发现阻断性的直接缺陷；两个 P2 证据缺口回流当前任务补验后复审。已通过 TypeScript、双实例创建、代理停机下的 Pi Web 模型调用、独立配置与密码、停止恢复和删除、探针未知状态、桌面/手机浏览器检查。旧 task/proxy 的部分回归需专用数据库，未在本验收库执行。Docker 容器不提供抵御不可信代码或内核漏洞的保证。
