# Pi 任务运行闭环评审

- 编号：REV-20260927-011
- 日期：2026-09-27
- 状态：修复后复审通过，进入正式隔离测试
- 范围：运行代理、任务工作进程、控制 API 编排、模型代理新增操作及任务页面
- 开发者验证：类型检查通过；真实 Pi 连续提问、自动轮换、停止/恢复、上游失败、回答中结束和删除通过；桌面/移动页面和只读文件/归属检查通过。

## 发现

1. REV-20260927-011-F001，P1：`codes/src/api/task-service.ts:95` 按读取到的单一状态执行停止转换但未检查转换结果。提问可在读取状态后进入 `answering`，导致授权和容器停止而状态仍被提问回调改回 `idle`。应以原子合法状态集合进入 `stopping`；提问状态和问答行也应事务提交。
2. REV-20260927-011-F002，P1：`codes/src/api/task-service.ts:153` 用页面最近 100 条列表进行生命周期对账；较老任务的令牌可能永不续期。失败补偿进入 `failed` 后也不再重试停止。调度应覆盖全部需管理任务，失败状态继续撤销与停止；过期/不匹配的文件授权须显式失败并收口。
3. REV-20260927-011-F003，P2：`codes/src/runtime-agent/task-runtime.ts:60` 只检查 Docker running，Pi 子进程退出但 HTTP 工作进程存活时仍被判断可提问。应核对受鉴权工作进程健康；容器异常不应停留在可提问状态。
4. REV-20260927-011-F004，P2：`codes/src/api/management-server.ts:38` 周期对账的外层数据库查询异常没有捕获，可能终止 API；`codes/src/runtime-agent/docker-engine.ts:34` 响应错误未传播，可能悬挂请求。应使用无敏感内容的失败记录并在下一周期重试，传播响应流错误。

## 残余边界

仅核查本地单实例与合成资料。运行代理持 Docker socket，仍有宿主级潜在权限；任务网络为内部 bridge，不等同于多租户强隔离。真实供应商兼容性、连接切换、资料上传与引用、多人配额和生产发布不在本轮。创建授权响应丢失且尚未写入任务表时，会留下到期授权元数据但没有任务容器；后续需设计持久操作幂等键与孤立记录清理。

## 复审

- F001 已解决：提问状态与问答行同一事务提交；结束以全部允许状态原子转换，迟到回答不能把 stopping 改回 idle。并发提问、迟到回调与停止状态的数据库测试通过。
- F002 已解决：后台查询全部非 stopped 任务，不受最近 100 条限制；失败状态持续重试撤销/停止；无可用授权明确失败并停止。102 条任务夹具、失败补偿、启动中断与丢失轮换确认测试通过。
- F003 已解决：运行状态分别返回 Docker running 与受鉴权工作进程 ready；工作进程启动时等待 Pi get_state 成功。杀死真实 Pi 子进程后 Docker running=true、ready=false 的检查通过。首次提问前空会话由 Pi 自身初始化，停止/恢复验证通过。
- F004 已解决：周期数据库异常捕获后只记录固定类别并重试；Docker 响应错误传递给调用者，错误仍被运行代理边界脱敏。

未发现剩余阻断性问题。轮换对账只列仍满足到期/交叠、活动任务与启用连接条件的授权，避免过期旧摘要被误认为可用。真实模型、多实例、复杂故障注入与生产运行仍不在本轮结论中。
