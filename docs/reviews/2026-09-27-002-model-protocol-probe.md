## 发现

### REV-20260927-002-F001（P1）：测试上游未校验代理认证替换

- 位置：`codes/probes/model-protocol/server.mjs` 的 `upstream` 请求处理入口。
- 触发与证据：代理用固定 `fixture-only` 认证发起上游请求，但测试上游只检查方法和路径，忽略 `Authorization`。即使代理错误地把 Pi 的 `probe-token-a` 原样转发，上游也会返回成功，整套验证仍可能通过。
- 影响：无法证明任务令牌没有越过代理边界，削弱 Backlog 2A 的核心验收。
- 修复方向：上游只接受夹具专用认证值，拒绝任何其他认证；验证脚本需要断言正常请求仍成功，并保证拒绝场景不会绕过代理。不得把认证值写入日志。

### REV-20260927-002-F002（P2）：创建失败时清理钩子可能删除同名旧资源

- 位置：`codes/probes/model-protocol/run.sh` 的 `cleanup` 和 `trap`。
- 触发与证据：退出钩子在 `docker network create` 前就注册，清理始终按生成名称运行。若 Docker 已有同名容器或网络，创建失败后钩子仍可能删除它。
- 影响：协议验证脚本可能误删并非本次创建的 Docker 资源。
- 修复方向：仅在成功创建对应资源后标记所有权，清理时检查标记；创建失败不清理已有资源。
