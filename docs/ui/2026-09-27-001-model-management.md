# 本地模型连接管理工作台

- 编号：UI-20260927-001
- 日期：2026-09-27
- 状态：本地单人增量设计
- 依据：[本地问答需求](../requirements/2026-09-27-001-document-qa-local-slice.md)、[管理授权决策](../decisions/2026-09-27-004-model-management-and-token-renewal.md)

管理员从本机回环地址进入工作台，使用仓库外密钥登录。在同一页面批准 HTTPS origin、查看已批准目标、创建模型连接并查看非敏感元数据；可停用连接或更换凭据。页面不展示或持久保存凭据，提交后清空输入。空列表、提交等待、字段错误、授权过期和服务故障须有明确反馈。移动窄屏时表格改为逐行信息布局，操作仍可用。登录与写入仅限已确认的本地单人环境。

本增量不提供连接删除、origin 撤销、任务绑定、真实模型测试调用和多人管理。状态文案不把已保存连接误称为可运行的任务代理。
