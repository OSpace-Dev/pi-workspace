# 资料问答界面

- 编号：UI-20260927-003；日期：2026-09-27；状态：已实现，桌面与手机受控验收通过
- 关联：[设计](../architecture/2026-09-27-010-document-qa.md)、[需求](../requirements/2026-09-27-001-document-qa-local-slice.md)

任务详情保持现有导航与生命周期操作。桌面资料栏与问答区双列，移动端资料在问答之前。资料栏有文件选择器、多选 TXT/Markdown、上传命令、文件名/字节/总用量、原文链接、明确错误；只有 idle/stopped 可上传，处理期间禁用重复提交。无资料继续原有问答。

回答分 claim 展示，每项下有文件名、章节/段落引用链接及“引文匹配”状态。无依据/资料冲突显示结果状态，引用无效显示失败原因而无有效出处链接。等待轮询提供阶段与经过时间，不展示推理或原始协议。

新增真实路由 /tasks/:id/sources/:sourceId。原文页面提供返回任务、文件元数据、全篇原文；引用携带 start/end 参数，高亮服务端已计算范围并滚动到定位。参数无效不高亮，文本始终安全渲染。刷新、未登录、已删除、长文件与移动端都有可恢复反馈。

保持现有操作型页面、统一字体/色彩，资料列表不使用嵌套卡片。键盘焦点可见，选择器/表单有标签，进度 aria-live，错误 role=alert；390x844 和 1280x800 验证无溢出，文本可换行。删除提示包含资料、会话和回答。
