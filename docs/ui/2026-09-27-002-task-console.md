# 本地 Pi 任务工作台

- 编号：UI-20260927-002
- 日期：2026-09-27
- 状态：已实现；桌面与窄屏页面操作通过隔离验收
- 依据：[本地问答需求](../requirements/2026-09-27-001-document-qa-local-slice.md)、[任务运行设计](../architecture/2026-09-27-009-pi-task-runtime.md)

`/tasks` 展示任务列表、状态、连接、最近活动和新建命令；`/tasks/:id` 展示对话与当前操作。顶层导航将“任务”和“模型管理”分开，模型管理保留现有两条真实路由。任务详情只在 `idle` 时可提问，只在 `stopped` 时可恢复；结束和删除须展示动作结果。停止、恢复、提问和删除都禁用重复提交。运行失败显示稳定错误类别与可执行的重试或删除操作，不把失败回答显示为成功。

删除确认明确说明任务的容器、工作目录、会话和问答记录均不可恢复。任务令牌、供应商凭据、完整 Docker 错误和原始 Pi RPC 记录不进入页面。空列表、无可用连接、网络故障、会话过期与窄屏布局都有明确状态。现有原生 ES modules 按任务列表、详情和 API/会话边界扩展，路由由服务端精确注册；未来引入 Vue/React 时采用对应路由体系，不在本轮为框架迁移制造双重实现。
