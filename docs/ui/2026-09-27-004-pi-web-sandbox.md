# 沙箱管理页面

- 编号：UI-20260927-004；日期：2026-09-27；状态：可实施
- 关联：[需求](../requirements/2026-09-27-002-pi-web-sandbox.md)、[设计](../architecture/2026-09-27-011-pi-web-sandbox.md)

主导航新增“沙箱”，路由 `/sandboxes`（列表与创建）及 `/sandboxes/:id`（详情）；保留任务与模型管理。列表按创建时间显示名称、模型连接、Pi Web/运行状态、创建时间、查看操作。创建对话框含名称与已启用模型连接，提交显示启动中，成功到详情；没有连接时指向模型管理。

详情显示名称、状态、连接、环境 ID、创建时间、Pi Web 当前地址、打开按钮、密码显示/复制按钮、停止/恢复/删除。密码默认遮挡，用户点击后仅在本次页面状态显示；不置入 URL、日志或表格。运行且健康才可打开；停止时禁用打开，地址可为空；恢复后重新读取 Docker 当前端口，旧地址不承诺保持。失败展示错误及可用操作。删除对话框明确容器、Pi 会话、文件、授权均将移除。

页面保持现有管理台密度、颜色和交互组件；独立 JS 模块承担列表、详情、访问凭据和状态操作，不叠加到任务模块。轮询只更新变化的节点，避免焦点丢失。移动端纵向布局、按钮可触达，无水平溢出；表单、密码、错误和状态有标签与 aria-live。Pi Web 自身视觉与交互来自固定第三方包，本轮不修改其源码。
