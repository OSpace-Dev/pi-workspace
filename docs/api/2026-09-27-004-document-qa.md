# 资料与问答契约

- 编号：API-20260927-004；日期：2026-09-27；状态：已实现，契约与受控端到端验收通过
- 消费者：本机管理浏览器；[设计](../architecture/2026-09-27-010-document-qa.md)
- 机器契约：[document-qa.yaml](../../codes/openapi/document-qa.yaml)

沿用 Cookie 会话、Host/Origin 和写操作 CSRF。GET /api/v1/tasks/:id/sources 返回 items（不含原文）；POST 同路径接收 {files:[{name,base64}]}，201 返回 items，上传请求限 450 KiB；无 multipart 依赖，base64 必须标准规范编码。GET /api/v1/tasks/:id/sources/:sourceId 返回 source，含 text。只允许 task 所属来源，不可跨任务查看。

现有 detail 新增每轮 sourceIds、result、phase；prompt 成功兼容 answer 并附 result。result 为 status 与 claims，citations 包含 sourceId/fileName/quote/start/end/location。旧普通问答 result=null。引用未通过则 502 CITATION_INVALID 或 ANSWER_FORMAT_INVALID；无 raw answer 暴露。

错误：400 DOCUMENT_INVALID_ENCODING/DOCUMENT_EMPTY/DOCUMENT_UNSUPPORTED/DOCUMENT_INVALID_NAME/DOCUMENT_INVALID_INPUT；413 DOCUMENT_FILE_TOO_LARGE/DOCUMENT_TOTAL_TOO_LARGE/DOCUMENT_TOO_MANY/DOCUMENT_CONTEXT_TOO_LARGE；409 DOCUMENT_DUPLICATE_NAME/TASK_NOT_IDLE；404 TASK_NOT_FOUND/SOURCE_NOT_FOUND。错误不含正文、凭据与内部地址。不自动重试上传/模型调用；同名使重复上传可辨识。读取顺序 created_at,id。来源不单独更新或删除。
