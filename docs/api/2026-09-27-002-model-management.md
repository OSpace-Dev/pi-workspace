## 用例与边界

管理员批准供应商 HTTPS origin，创建并查看模型连接、停用连接和更换凭据。浏览器不能调用模型代理或运行代理，也不能读取密文或明文。模型调用沿用独立的 [Pi 代理契约](2026-09-27-001-model-proxy.md)；任务创建、切换和恢复 API 另行设计。

本地工作台使用 `/api/v1/origins` 与 `/api/v1/connections`，内部管理路径不发布宿主端口。见[机器可读契约](../../codes/openapi/model-management.yaml)及[管理任务](../planning/2026-09-27-010-model-management-console.md)。origin 重复批准幂等，连接创建不提供重试幂等键，调用方遇到不确定响应时先刷新列表。停用与凭据更换使用响应中的不透明 `version` 检查并发变化；当前不支持删除或撤销 origin。

| 操作 | 输入与成功结果 | 关键约束 |
| --- | --- | --- |
| 列出批准目标 | 返回规范化 origin、创建时间 | 不包含任意 URL 探测能力 |
| 批准 origin | 无路径的 HTTPS origin；返回规范化值 | 管理员授权；精确匹配；重复提交幂等 |
| 创建连接 | 显示名、base URL、模型 ID、凭据；返回非敏感元数据 | 目标已批准；DNS/地址策略通过；请求体和响应均不得记录或回显凭据 |
| 列出/读取连接 | 元数据、启用状态和凭据已配置布尔值 | 不返回密文或凭据片段 |
| 停用连接 | 连接 ID 和并发版本；返回新状态 | 拒绝后续调用并处理绑定任务；重复提交幂等 |
| 更换凭据 | 连接 ID、并发版本、新凭据；返回新版本与非敏感元数据 | 不允许空值表示清除；并发冲突须显式报告 |

原地更换目标/模型、删除连接和撤销 origin 暂不纳入上述最小写入面；其对运行任务的影响需先确认。任何内部管理调用都要验证 API 的服务身份和操作权限，不接受任务代理令牌。浏览器使用已确认的本地管理员密钥与受保护会话，写入检查 Host、Origin 和 CSRF；API 只瞬时转送凭据明文，模型代理负责加密。

本地实现的错误响应为 `{ "error": { "code": "..." } }`，不含输入值或上游正文。未授权 401/403、并发冲突 409、超限 413、目标校验失败 422、DNS 暂不可用 503；API 到管理服务超时为 10 秒。当前单人列表返回全部记录，不提供分页；连接创建不支持幂等键，网络结果不确定时应先刷新列表。管理操作审计、分页和多用户错误追踪列入后续设计。机器可读 OpenAPI 已随本地实现交付，真实供应商与任务代理契约需独立验收。
