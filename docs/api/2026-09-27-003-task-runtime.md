## 页面 API

| 操作 | 语义 | 成功 | 失败与重复 |
| --- | --- | --- | --- |
| GET /api/v1/tasks | 创建时间倒序的最近 100 条任务 | 200 items | 401 会话失效；调度查询不受此列表限制 |
| POST /api/v1/tasks | 选择 connectionId，创建并启动独立环境 | 201 task | 400 输入、409 不可用连接、503 启动失败；请求超时不自动重试创建 |
| GET /api/v1/tasks/{id} | 查看状态与有序问答 | 200 task/turns | 404 不存在 |
| POST /api/v1/tasks/{id}/prompt | 纯文本提问，等待一轮回答 | 200 turnId/answer | 409 非 idle 或忙、502 回答失败；不自动重试计费操作 |
| POST /api/v1/tasks/{id}/stop | 撤销授权与活动流后停容器 | 200 stopped task | 重复停止幂等；503 未完成则可重试 |
| POST /api/v1/tasks/{id}/resume | 同一容器/会话，以新令牌恢复 | 200 idle task | 409 非 stopped、会话缺失；503 保留故障记录 |
| DELETE /api/v1/tasks/{id} | 删除匹配环境及问答/授权记录 | 204 | 404 已不存在；503 保留 deleting 可重试 |

现有管理员会话、Host/Origin 与 CSRF 校验适用。提问最大 32 KiB UTF-8；页面请求体上限 40 KiB；不接受任意 RPC、Docker 参数、上游地址或请求头。时间为 ISO 8601，任务与连接 ID 为 UUID。原始任务令牌、供应商凭据、授权摘要和 Docker 工作密钥不会返回浏览器。回答是最终纯文本，页面显示等待状态；逐字事件与资料引用在文档问答增量交付。

## 内部运行操作

运行代理只在内部网络接受服务 Bearer 凭据：GET `/internal/tasks/{id}` 返回容器/工作进程状态、会话存在性和当前文件的 SHA-256 指纹；POST 后缀 `prepare`（modelId/token）、`token`（token）、`resume`（token）、`stop`、`delete`、`prompt`（message）。所有任务 ID 均验证 UUID，容器同时核验任务标签、镜像和三项专属挂载。创建/恢复等待最多约 35 秒；提问控制 API 最多等待 130 秒，工作进程在 120 秒结束失败请求。模型调用不自动重试。

模型代理新增 POST `/internal/tasks/{id}/resume`、`rotate`（connectionId/previousGrantId）、`rotation/finish`、`rotation/abort`（grantId）以及 GET `/internal/tasks/{id}/grants`（仅摘要与轮换元数据）。令牌原值只在签发响应中返回控制域，文件更新后用指纹对账；内部响应也不记录正文。停止重试仍取消本进程活动流。

## 容错与限制

本地单实例 API 每 30 秒对全部需管理任务做对账与续期，页面列表的截断不影响调度。正在回答最多占用两分钟，调度将在其后续期，已确认的十分钟提前窗口保留余量。故障补偿持续撤销授权和停止，不把未知状态标记成功。启动时打断遗留回答并记录失败；轮换确认丢失按文件指纹完成或撤销，不能盲目撤销文件已使用的新令牌。

创建、提问目前没有持久幂等键，响应丢失时先刷新列表/记录，再决定操作。多人并发、配额、分页查询、操作审计与生产身份不在该本地契约；扩展前重新设计。根文件系统只读，本轮没有依赖安装行为；恢复验证证明工作目录和 Pi 会话，不证明未来依赖安装能力。
