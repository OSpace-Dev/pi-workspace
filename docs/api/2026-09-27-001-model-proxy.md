## 用例和兼容性

使用 Pi `models.json` 的 `openai-completions` 提供者；`baseUrl` 指向模型代理的内部 `/v1`，`apiKey` 是当前任务的代理令牌。代理不对浏览器开放，也不提供任意路径转发。此接口只适配首轮纯文本、无工具调用的 Chat Completions 流式请求；其它 Pi API 类型、图片、工具调用和非流式请求不在本契约内。

协议路径固定为 `POST /v1/chat/completions`，`Content-Type: application/json`，`Authorization: Bearer <task-token>`。请求至少包含字符串 `model`、非空 `messages` 和 `stream: true`；允许 `stream_options.include_usage`。本次固定模型配置的 Pi 0.87.1 实测请求字段为 `max_completion_tokens`、`messages`、`model`、`stream`、`stream_options`。其它兼容性配置可能产生不同字段，须逐连接验证后加入白名单。`model` 只能等于任务绑定的模型 ID。上游地址和真实密钥只能来自代理控制域的模型连接配置。

成功时返回 HTTP 200、`Content-Type: text/event-stream`，按 OpenAI Chat Completions SSE 顺序转发 `data: {...}` 分块及正常结束。代理不得把真实上游认证头转回 Pi。流内容和最终 `finish_reason` 是否需转换，以 Pi 0.87.1 的实测为准；首个验证仅接受被测试上游实际支持的字段。

## 错误与运行行为

| 情况 | 响应或事件 | 说明 |
| --- | --- | --- |
| 缺失、无效、撤销或不属于任务的令牌 | 401 或 403，稳定错误码 | 不暴露任务是否存在、连接详情或令牌片段 |
| 非法 JSON、超限、非流式、模型不匹配或工具字段 | 400 或 413，稳定错误码 | 在访问上游前拒绝 |
| 无可用模型连接或目标被拒绝 | 409 或 502，稳定错误码 | 不回显上游 URL |
| 上游在流开始前失败 | 502 或 504，稳定错误码 | 不透传上游响应正文、认证头和错误元数据 |
| 上游在流开始后失败或客户端取消 | 终止流并留内部故障类别 | 不伪造成功的 `[DONE]`；以 Pi 实测确认最终失败事件 |

首响应 15 秒、流空闲 30 秒；请求正文上限 1 MiB、消息最多 64 条、完成 token 1～4096，省略时代理补 4096；响应流上限 4 MiB。单任务一条活动流、单进程八条，超限返回 429 `TOO_MANY_STREAMS`。这些是本地技术限额，不代表多人容量承诺。

稳定错误码为 `UNAUTHORIZED`、`INVALID_REQUEST`、`MODEL_MISMATCH`、`CONNECTION_UNAVAILABLE`、`TARGET_UNAVAILABLE`、`TOO_MANY_STREAMS`、`UPSTREAM_FAILED`、`INTERNAL_ERROR`；框架 JSON 解析和正文超限使用无敏感内容的 `INVALID_INPUT`。代理不重试；受控 Pi 配置必须禁用 Agent 和 provider 自动重试。任务停止会撤销令牌并取消活动流。删除、切换、恢复和自动续期在运行代理增量实现；令牌有效期为 1 小时，提前 10 分钟轮换、最多 5 分钟交叠，见[时间窗口决策](../decisions/2026-09-27-005-task-token-window.md)。外部接口版本以 `/v1` 表示 Pi 兼容路径；破坏性变更需同步任务镜像和契约测试。[边界决策](../decisions/2026-09-27-002-model-proxy-boundary.md)约束出站目标。

控制域另有 `POST /internal/tasks` 和 `POST /internal/tasks/{id}/stop`，使用独立服务凭据。首次签发的原始令牌只在创建响应中返回，浏览器控制 API不提供这些路由。代理任务状态表示模型授权，不证明 Pi 容器已运行；停止重复请求返回 404，不会恢复授权。

## 验证门槛

1. 已用无真实凭据的固定测试上游验证独立 Pi 0.87.1 容器的一轮流式回答：两个 `text_delta`、最终 `message_end.stopReason: stop` 和 `agent_settled`。
2. 无效令牌返回 401；任务 A 令牌访问任务 B 模型返回 403；请求携带目标覆盖字段也返回 403，均未到测试上游。
3. 上游非 2xx 和断流分别使 Pi 最终 `stopReason: error`，两者仍产生 `agent_settled`；含假敏感文本的上游错误正文未出现在 Pi 事件或夹具日志中。测试上游会拒绝未由代理替换的认证值。
4. 历史协议证据见协议验收。本轮产品代码的 Pi/TLS、状态撤销、停止竞态和页面回归见受控调用验收。真实供应商兼容性和正式运行代理仍未覆盖。
